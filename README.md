# 🚀 Workwii — Tu Aliado Inteligente para Conseguir Empleo

**Workwii** es una plataforma web premium y moderna diseñada para revolucionar la forma en que los profesionales preparan sus postulaciones laborales. Ofrece herramientas inteligentes e interactivas que te ayudan a estructurar tu currículum, superar los exigentes filtros ATS (Applicant Tracking Systems) y entrenar tus respuestas en simulacros de entrevistas reales impulsados por Inteligencia Artificial.

---

## ✨ Servicios Principales

### 📝 Editor de CV en Tiempo Real
* **Lienzo Limpio e Intuitivo:** Espacio de trabajo de alto rendimiento libre de distracciones para redactar tu perfil profesional y experiencia laboral.
* **Autoguardado Inteligente (Autosave):** Cada cambio que realices en el título o contenido se guarda automáticamente en la nube de forma asíncrona mediante un sistema con debounce que optimiza la carga del navegador.
* **Sincronización en Tiempo Real:** Sincronizado mediante WebSockets con la base de datos para que puedas editar desde cualquier pestaña o dispositivo sin perder información.

### 🔍 Optimización y Filtro ATS
* **Supera los Filtros de Reclutamiento:** Analiza tu currículum frente a las palabras clave técnicas y competencias requeridas por los filtros automáticos que usan las grandes empresas.
* **Vocabulario de Alto Impacto:** Sugerencias y guías dinámicas para adaptar la redacción de tus logros utilizando métricas y resultados cuantitativos.

### 🤖 Simulador de Entrevistas IA (ChatWil)
* **Entrenador Virtual de Confianza:** Simula entrevistas de trabajo personalizadas según tu especialidad laboral o puesto objetivo.
* **Feedback Constructivo al Instante:** ChatWil evalúa tus respuestas una a una, dándote consejos prácticos para mejorar tu comunicación, coherencia y seguridad antes de la entrevista real.

### 📓 Gestor de Notas y Apuntes
* **Organización Sin Esfuerzo:** Un cuaderno de notas seguro e integrado para registrar logros profesionales, borradores de cartas de presentación y recordatorios de postulaciones activas.
* **Caché Offline-First:** Accede instantáneamente a tus notas preferidas de forma local antes de sincronizarse con la base de datos.

### 📰 Blog & Guías de Empleo
* **Recursos de Alto Valor:** Artículos detallados, plantillas optimizadas y estrategias de búsqueda eficientes para potenciar tu marca personal y llamar la atención de los reclutadores.

## 💎 Excelentes Beneficios

* ⚡ **Carga Ultrarrápida:** Arquitectura de carga premium optimizada para un rendimiento óptimo de 99% de velocidad.

## 🛠️ Stack Tecnológico

* **Core Framework:** [Astro 6](https://astro.build/) (Renderizado estático/híbrido ultra veloz).
* **Base de Datos y Auth:** [Supabase](https://supabase.com/) (Autenticación OAuth, base de datos relacional Postgres y suscripciones Realtime).
* **Lenguaje:** Vanilla Javascript & CSS3 moderno.
* **Iconografía:** FontAwesome inyectado dinámicamente.

## 🧞 Instrucciones de Desarrollo

Para ejecutar el proyecto localmente, sigue estos pasos:

1. **Instalar dependencias:**
   ```sh
   pnpm install
   ```

2. **Iniciar servidor de desarrollo:**
   ```sh
   pnpm dev
   ```
   La aplicación estará disponible localmente en `http://localhost:4321`.

3. **Compilar para producción:**
   ```sh
   pnpm build
   ```
   Genera la versión optimizada en el directorio `./dist/`.

4. **Previsualizar compilación:**
   ```sh
   pnpm preview
   ```
